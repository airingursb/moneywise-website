# 개인정보 처리방침

**시행일:** 2026-11-24

본 방침은 MoneyWise가 사용자의 데이터를 어떻게 처리하는지 설명합니다.

## 요약 (TL;DR)

- 모든 금융 기록은 로컬 데이터베이스로 **사용자의 기기에** 저장되며, 기기에 내장된 보안 기능(앱 샌드박스 및, 활성화된 경우 기기 암호화)으로 보호됩니다.
- 앱은 **사용 통계**(사용한 화면과 기능)를 저희가 직접 운영하는 Umami 서버로 전송하며 — 설정 › 계정 및 데이터 › 보안 및 개인정보에서 끌 수 있습니다 — 버그 수정을 위해 **크래시 및 성능 리포트**를 Sentry로 전송합니다. 광고를 게재하지 않으며 데이터를 판매하지 않습니다.
- **클라우드 동기화**(Pro)를 활성화하면 데이터는 암호화된 연결(TLS)을 통해 저희 Supabase 백엔드로 전송되어 사용자의 계정에 저장되며, 행 수준 접근 규칙에 따라 다른 사용자와 분리됩니다. 종단 간 암호화는 적용되지 않습니다.
- 본인의 API 키로 **AI 어드바이저**를 사용할 경우, 요청은 기기에서 AI 제공자에게 직접 전송됩니다. 저희는 그 요청을 중계하거나 기록하거나 라우팅하지 않습니다.
- 이 웹사이트(`moneywise.ursb.me`)는 프라이버시를 존중하는 쿠키 없는 페이지뷰 분석을 위해 **Umami**를 사용합니다. IP 주소나 개인 식별 정보는 저장되지 않습니다.

## MoneyWise가 수집하는 정보

**사용자의 기기 안에서**(동기화를 활성화하지 않는 한 저희 서버에 업로드되지 않음. AI 기능은 아래 설명대로 필요한 정보를 사용자가 선택한 제공자에게 전송함):
- 계정·잔액·거래 기록·예산·투자 보유 종목.
- 사용자가 첨부하기로 선택한 영수증 이미지.
- AI 제공자의 API 키 (기기의 보안 저장소 — iPhone과 Mac은 키체인, Android는 Keystore — 에 저장). 저희 서버로는 절대 전송되지 않습니다.

**클라우드 동기화가 활성화된 경우**(Pro 구독자):
- 위 데이터의 사본 (TLS로 전송되어 저희 Supabase 백엔드의 사용자 계정에 저장). 행 수준 보안 규칙에 따라 접근은 사용자 본인의 계정(및 사용자가 참여한 가족 워크스페이스의 멤버)으로 제한됩니다.
- Supabase 계정용 이메일 주소 (로그인 용도로만 사용).
- 동기화 시 다른 기기를 식별하기 위한 기기 식별자.

**AI 기능을 사용할 경우:**
- AI 기능은 항상 사용자 본인의 Anthropic 또는 OpenAI API 키를 사용하며, MoneyWise는 공용 AI 크레딧을 제공하지 않습니다. 요청은 기기에서 사용자가 선택한 제공자에게 직접 전송되며, 해당 기능에 필요한 정보만 포함됩니다(예: 월간 리뷰를 위한 지출 집계 수치, 투자 일일 리포트를 위한 보유 종목). 스캔한 영수증 사진은 판독을 위해 해당 제공자에게 전송됩니다.

**앱 내 진단 정보:**
- 사용 통계: 사용한 화면과 기능, 앱 버전, 언어, 기기 유형을 저희가 직접 운영하는 Umami 서버로 전송합니다. 설정 › 계정 및 데이터 › 보안 및 개인정보에서 끌 수 있습니다.
- 크래시 및 성능 리포트: 오류 상세 정보, 기기 및 OS 정보, IP 주소를 Sentry로 전송합니다. 사용 통계 스위치로는 이 리포트를 끌 수 없습니다.

**MCP 확장으로 AI 어시스턴트를 연결한 경우**(Pro):
- 사용자가 승인한 어시스턴트는 사용자가 생성한 토큰 또는 OAuth 권한을 사용해 저희 MCP 서버를 통해 동기화된 계정의 데이터를 읽을 수 있으며, 허용한 경우 데이터를 생성할 수도 있습니다. 앱에서 언제든지 접근 권한을 취소할 수 있습니다.

**피드백을 보낼 경우:**
- 앱에서 제출한 버그 신고와 기능 요청은 후속 연락을 위해 계정 이메일과 함께 저희 이슈 트래커(Linear)에 저장됩니다.

**이 웹사이트에서:**
- Umami가 기록하는 항목: 조회한 페이지·리퍼러·국가(대략)·브라우저/OS(대략)·화면 크기. 개인을 식별하는 정보는 포함되지 않습니다.
- 쿠키 없음. 트래킹 픽셀 없음. 광고 네트워크 없음.

## MoneyWise가 수집하지 **않는** 정보

- 정확한 위치 정보를 수집하지 않습니다.
- 데이터를 제3자에게 공유·판매·임대하지 않습니다.
- 광고를 게재하지 않습니다.
- 사용자가 요청한 지원을 제공하거나 법률상 요구되는 경우를 제외하고는 사용자의 금융 기록에 접근하지 않습니다.

## 사용자의 권한

- **내보내기**: 앱 내에서 모든 기록을 CSV로 내보낼 수 있습니다.
- **삭제**: 앱에서 계정을 삭제하면(설정 › 내 계정 › 계정 삭제) 클라우드 데이터가 제거되며, 앱을 삭제하면 로컬 데이터가 제거됩니다. 아래 연락처로 이메일을 보내 요청할 수도 있습니다.
- **동기화 중지**: 클라우드 동기화를 끄면 이후 업로드가 중단됩니다. 이미 동기화된 데이터는 계정을 삭제할 때까지 계정에 남아 있습니다.
- **분석**: 설정 › 계정 및 데이터 › 보안 및 개인정보에서 사용 통계를 끌 수 있습니다.

## 제3자 서비스

| 서비스 | 용도 | 위치 |
|---|---|---|
| Supabase | 클라우드 동기화 백엔드, 인증, 파일 저장소 | eu-west (아일랜드) |
| Apple | App Store, 인앱 결제, Apple로 로그인, iCloud 키체인 | Apple |
| Google | Google 로그인, Google Play 결제 | Google |
| Adapty | 구독 상태 및 구매 검증 | Adapty |
| Sentry | 크래시 및 성능 리포트 | 미국 |
| 사용자가 선택한 AI 제공자 (Anthropic, OpenAI) | AI 요청은 사용자의 키로 기기에서 직접 전송 | 미국 |
| Yahoo Finance (저희 서버 경유) | 보유 종목 티커의 시세 | 미국 |
| Linear | 사용자가 제출한 버그 신고 및 기능 요청 | 미국 |
| Umami (셀프 호스트) | 웹사이트 분석 및 앱 내 사용 통계 | 저희 서버 |
