# 隱私權政策

**生效日期：** 2026-11-24

本政策說明 MoneyWise 如何處理你的資料。

## 摘要（簡短版）

- 你所有的財務紀錄都**存放在你的裝置上**的本機資料庫中，受裝置內建的安全機制保護（App 沙盒，以及在已啟用時的裝置加密）。
- 應用程式會將**使用統計**（使用了哪些畫面與功能）傳送到我們自行架設的 Umami 伺服器，並將**當機與效能報告**傳送到 Sentry，以便我們修正錯誤。「設定 › 帳戶與資料 › 安全與隱私」裡的同一個開關可以把兩者都關閉。我們不投放廣告，也不出售你的資料。
- 如果你開啟了**雲端同步**（Pro），資料會透過加密連線（TLS）傳送到我們的 Supabase 後端並存放在你的帳戶中，由資料列層級的存取規則與其他使用者隔離。這不是端對端加密。
- 如果你使用自己的 API 金鑰啟用 **AI 顧問**，請求會直接從你的裝置發送到 AI 服務商，我們不會路由、記錄或中轉這些請求。
- 本網站（`moneywise.ursb.me`）使用 **Umami** 進行注重隱私的無 Cookie 網頁瀏覽統計，不存放 IP 位址或任何可識別資訊。

## MoneyWise 收集的資訊

**在你的裝置上**（除非啟用同步，否則不會上傳到我們的伺服器；AI 功能會將所需內容傳送給你選擇的服務商，詳見下文）：
- 你的帳戶、餘額、交易紀錄、預算和投資持倉。
- 你選擇附加的收據圖片。
- 你的 AI 服務商 API 金鑰（存放在裝置的安全儲存區——iPhone 與 Mac 上為鑰匙圈，Android 上為 Keystore）。它絕不會被傳送到我們的伺服器。

**開啟雲端同步時**（Pro 訂閱者）：
- 以上資料的副本，透過 TLS 傳送並存放在我們 Supabase 後端中你的帳戶裡。存取權限透過資料列層級安全規則（row-level security）限定於你的帳戶（以及你加入的家庭工作區成員）。
- 你的 Supabase 帳戶電子郵件（僅用於登入）。
- 用於在同步過程中區分不同裝置的裝置識別碼。

**使用 AI 功能時：**
- AI 功能一律使用你自己的 Anthropic 或 OpenAI API 金鑰；MoneyWise 不提供共享 AI 額度。請求會直接從你的裝置發送到你選擇的服務商，且只包含該功能所需的內容（例如月度回顧所需的彙總支出數據，或投資每日報告所需的持倉）。你掃描的收據照片會傳送給該服務商進行辨識。

**應用程式內診斷資料：**
- 使用統計：使用了哪些畫面與功能、App 版本、語言與裝置類型，傳送到我們自行架設的 Umami 伺服器。你可以在「設定 › 帳戶與資料 › 安全與隱私」中關閉。
- 當機與效能報告：錯誤詳情、呼叫堆疊、裝置型號、系統版本和 App 版本，傳送到 Sentry。不包含你的 IP 位址、帳戶資訊或財務資料。關閉使用統計的同一個開關也會關閉這些報告。

**如果你透過 MCP 擴充連接 AI 助理**（Pro）：
- 你授權的助理可以透過我們的 MCP 伺服器，使用你建立的權杖或 OAuth 授權，讀取你已同步帳戶中的資料（若你允許，也能建立資料）。你可以隨時在 App 中撤銷存取權。

**當你傳送意見回饋時：**
- 你在 App 中提交的錯誤回報與功能建議，會連同你的帳戶電子郵件存放在我們的問題追蹤系統（Linear）中，以便我們後續聯繫。

**在本網站：**
- Umami 記錄：瀏覽頁面、來源網址、國家（粗粒度）、瀏覽器 / 作業系統（粗粒度）、螢幕尺寸。不包含任何可識別個人身份的資訊。
- 無 Cookie，無追蹤像素，無廣告網路。

## MoneyWise **不**收集的資訊

- 我們不收集你的精確位置。
- 我們不向第三方共享、出售或出租資料。
- 我們不投放廣告。
- 除非是為了提供你所要求的支援，或依法律要求，我們不會存取你的財務紀錄。

## 你的控制權

- **匯出**：在應用程式內，你可以將所有紀錄匯出為 CSV 檔案。
- **刪除**：在 App 內刪除帳號（「設定 › 我的帳號 › 刪除帳號」）即可移除你的雲端資料；解除安裝應用程式會刪除本機資料。你也可以透過下方聯絡方式寄信給我們。
- **停止同步**：關閉雲端同步後將停止後續上傳。已同步的資料會保留在你的帳戶中，直到你刪除帳號為止。
- **分析**：可在「設定 › 帳戶與資料 › 安全與隱私」中關閉使用統計。
