# プライバシーポリシー

**発効日：** 2026-11-24

このポリシーは、MoneyWise があなたのデータをどのように扱うかを説明します。

## 概要（要点のみ）

- すべての財務記録は、ローカルデータベースとして**あなたのデバイスに**保存され、デバイスに組み込まれたセキュリティ（アプリのサンドボックスと、有効な場合はデバイスの暗号化）によって保護されます。
- アプリは**利用統計**（使用された画面や機能）を当社がセルフホストする Umami サーバーに送信します——これは 設定 › アカウントとデータ › セキュリティとプライバシー でオフにできます。また、不具合を修正するために**クラッシュ・パフォーマンスレポート**を Sentry に送信します。広告は配信せず、データを販売することもありません。
- **クラウド同期**（Pro）を有効にした場合、データは暗号化された通信（TLS）で当社の Supabase バックエンドに送信され、あなたのアカウントに保存されます。行レベルのアクセスルールによって他のユーザーから分離されます。エンドツーエンド暗号化ではありません。
- 自分の API キーで **AI アドバイザー**を使用する場合、リクエストはデバイスから AI プロバイダーに直接送信されます。私たちがそれらのリクエストを中継・記録・ルーティングすることはありません。
- このウェブサイト（`moneywise.ursb.me`）では、プライバシーに配慮したクッキーなしのページビュー分析のために **Umami** を使用しています。IP アドレスや個人識別情報は保存されません。

## MoneyWise が収集する情報

**あなたのデバイス上**（同期を有効にしない限り当社のサーバーにはアップロードされません。AI 機能は、下記のとおり必要な情報を選択したプロバイダーに送信します）：
- 口座・残高・取引記録・予算・投資保有銘柄。
- 添付を選択したレシート画像。
- AI プロバイダーの API キー（デバイスのセキュアストレージに保存——iPhone と Mac ではキーチェーン、Android では Keystore）。当社のサーバーに送信されることはありません。

**クラウド同期が有効な場合**（Pro サブスクライバー）：
- 上記のデータのコピー（TLS で送信され、当社の Supabase バックエンド上のあなたのアカウントに保存）。アクセスは行レベルのセキュリティルールにより、あなたのアカウント（および参加した家族ワークスペースのメンバー）に制限されます。
- Supabase アカウントのメールアドレス（ログインのみに使用）。
- 同期中に異なるデバイスを識別するためのデバイス識別子。

**AI 機能を使用する場合：**
- AI 機能は常にあなた自身の Anthropic または OpenAI の API キーを使用します。MoneyWise は共有 AI クレジットを提供していません。リクエストはデバイスから選択したプロバイダーに直接送信され、その機能に必要な情報のみが含まれます（例：月次レビューでは集計された支出額、投資のデイリーレポートでは保有銘柄）。読み取りを行うレシート写真は、内容の読み取りのためにそのプロバイダーに送信されます。

**アプリ内の診断情報：**
- 利用統計：使用された画面や機能、アプリのバージョン、言語、デバイスの種類。当社がセルフホストする Umami サーバーに送信されます。設定 › アカウントとデータ › セキュリティとプライバシー でオフにできます。
- クラッシュ・パフォーマンスレポート：エラーの詳細、デバイスと OS の情報、IP アドレス。Sentry に送信されます。利用統計のスイッチではオフになりません。

**MCP 拡張機能で AI アシスタントを接続する場合**（Pro）：
- あなたが許可したアシスタントは、あなたが作成したトークンまたは OAuth の許可を使い、当社の MCP サーバーを通じて同期済みアカウントのデータを読み取ること（許可した場合は作成すること）ができます。アクセスはアプリ内でいつでも取り消せます。

**フィードバックを送信する場合：**
- アプリ内から送信された不具合報告や機能リクエストは、フォローアップのためにアカウントのメールアドレスとともに当社の課題管理ツール（Linear）に保存されます。

**このウェブサイトでは：**
- Umami が記録するもの：閲覧ページ・参照元・国（概略）・ブラウザ / OS（概略）・画面サイズ。個人を特定するものは含みません。
- クッキーなし。トラッキングピクセルなし。広告ネットワークなし。

## MoneyWise が収集**しない**情報

- 正確な位置情報は収集しません。
- データを第三者と共有・販売・賃貸することはありません。
- 広告を配信しません。
- あなたが依頼したサポートを提供する場合、または法律で求められる場合を除き、あなたの財務記録にアクセスすることはありません。

## あなたのコントロール

- **エクスポート**：アプリ内ですべての記録を CSV にエクスポートできます。
- **削除**：アプリ内でアカウントを削除すると（設定 › マイアカウント › アカウントを削除）、クラウド上のデータが削除されます。アプリをアンインストールするとローカルデータが削除されます。以下の連絡先にメールでご依頼いただくこともできます。
- **同期の停止**：クラウド同期を無効にすると、それ以降のアップロードが停止します。すでに同期されたデータは、アカウントを削除するまでアカウントに残ります。
- **分析**：設定 › アカウントとデータ › セキュリティとプライバシー で利用統計をオフにできます。

## サードパーティサービス

| サービス | 用途 | 所在地 |
|---|---|---|
| Supabase | クラウド同期バックエンド、認証、ファイルストレージ | eu-west（アイルランド） |
| Apple | App Store、アプリ内購入、Apple でサインイン、iCloud キーチェーン | Apple |
| Google | Google ログイン、Google Play の課金 | Google |
| Adapty | サブスクリプションの状態と購入の検証 | Adapty |
| Sentry | クラッシュ・パフォーマンスレポート | 米国 |
| 選択した AI プロバイダー（Anthropic、OpenAI） | AI リクエストはあなたのキーを使ってデバイスから直接送信 | 米国 |
| Yahoo Finance（当社サーバー経由） | 保有銘柄のティッカーの市場価格 | 米国 |
| Linear | あなたが送信した不具合報告と機能リクエスト | 米国 |
| Umami（セルフホスト） | ウェブサイト分析とアプリ内の利用統計 | 当社サーバー |
