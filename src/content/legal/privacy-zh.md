# 隐私政策

**生效日期：** 2026-11-24

本政策说明 MoneyWise 如何处理你的数据。

## 摘要（简短版）

- 你的所有财务记录均**存储在你的设备上**的本地数据库中，受设备内置的安全机制保护（应用沙盒，以及在已启用时的设备加密）。
- 应用会将**使用统计**（使用了哪些页面和功能）发送到我们自托管的 Umami 服务器——你可以在「设置 › 账户与数据 › 安全与隐私」中关闭——并将**崩溃与性能报告**发送到 Sentry，以便我们修复问题。我们不投放广告，也不出售你的数据。
- 如果你开启了**云同步**（Pro），数据会通过加密连接（TLS）发送到我们的 Supabase 后端并存储在你的账户中，由行级访问规则与其他用户隔离。云同步并非端到端加密。
- 如果你使用自己的 API 密钥启用 **AI 顾问**，请求会直接从你的设备发送到 AI 服务商，我们不会路由、记录或中转这些请求。
- 本网站（`moneywise.ursb.me`）使用 **Umami** 进行注重隐私的无 Cookie 页面访问统计，不存储 IP 地址或任何可识别信息。

## MoneyWise 收集的信息

**在你的设备上**（除非启用同步，否则不会上传到我们的服务器；AI 功能会将所需内容发送给你选择的服务商，详见下文）：
- 你的账户、余额、交易记录、预算和投资持仓。
- 你选择附加的收据图片。
- 你的 AI 服务商 API 密钥（存储在设备的安全存储中——iPhone 和 Mac 上为钥匙串，Android 上为 Keystore）。它从不会发送到我们的服务器。

**开启云同步时**（Pro 订阅者）：
- 以上数据的副本，通过 TLS 传输并存储在我们 Supabase 后端中你的账户里。行级安全规则将访问权限限制在你的账户（以及你加入的家庭工作区成员）范围内。
- 你的 Supabase 账户邮箱（仅用于登录）。
- 用于在同步过程中区分不同设备的设备标识符。

**使用 AI 功能时：**
- AI 功能始终使用你自己的 Anthropic 或 OpenAI API 密钥；MoneyWise 不提供共享 AI 额度。请求从你的设备直接发送到你选择的服务商，且只包含该功能所需的内容（例如月度回顾所用的汇总支出数据，或投资日报所用的持仓信息）。你扫描的收据照片会发送给该服务商进行识别。

**应用内诊断：**
- 使用统计：使用了哪些页面和功能、App 版本、语言和设备类型，发送到我们自托管的 Umami 服务器。你可以在「设置 › 账户与数据 › 安全与隐私」中关闭。
- 崩溃与性能报告：错误详情、设备与操作系统信息以及你的 IP 地址，发送到 Sentry。使用统计开关不会关闭这些报告。

**如果你通过 MCP 扩展连接 AI 助手**（Pro）：
- 你授权的助手可以使用你创建的令牌或 OAuth 授权，通过我们的 MCP 服务器读取你已同步账户中的数据——如果你允许，还可以创建数据。你可以随时在 App 中撤销访问权限。

**当你发送反馈时：**
- 你在 App 中提交的问题反馈和功能建议会连同你的账户邮箱一起存储在我们的问题追踪系统（Linear）中，以便我们跟进。

**在本网站：**
- Umami 记录：浏览页面、来源网址、国家（粗粒度）、浏览器 / 操作系统（粗粒度）、屏幕尺寸。不包含任何可识别个人身份的信息。
- 无 Cookie，无追踪像素，无广告网络。

## MoneyWise **不**收集的信息

- 我们不收集你的精确位置。
- 我们不向第三方共享、出售或出租数据。
- 我们不投放广告。
- 除非为提供你所请求的支持或法律要求，我们不会访问你的财务记录。

## 你的控制权

- **导出**：在应用内，你可以将所有记录导出为 CSV 文件。
- **删除**：在 App 中删除账号（设置 › 我的账号 › 删除账号）即可移除你的云端数据；卸载应用将删除本地数据。你也可以通过下方联系方式发邮件给我们。
- **停止同步**：关闭云同步后将不再上传新数据。已同步的数据会保留在你的账户中，直到你删除账号。
- **分析统计**：在「设置 › 账户与数据 › 安全与隐私」中关闭使用统计。
